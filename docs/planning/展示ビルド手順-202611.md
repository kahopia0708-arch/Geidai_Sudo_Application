# 11月展示ビルド手順（iPad）

最終更新: 2026-10-30（Issue #29 / Epic #33）

## 1. 展示モードの ON

1. Unity で `Assets/Resources/Geidai/ExhibitionSettings.asset` を開く
2. **Is Exhibition Mode** にチェック
3. 保存（Resources に置いたままビルドする）

| 項目 | 展示 ON 時の動き |
|------|------------------|
| Skip Boot Screen | メイン（Boot）の「はじめる」なしで自動ルーティング |
| Allow Home Without Profile | 未登録 iPad でも Home へ（Register スキップ） |
| Home Menu Config Resources Path | `Geidai/HomeMenuConfig_Exhibition`（**おとあそび**・**おとずかん**のみ） |
| Blocked Scenes | Rec / Create / Collection / Theme へ `GoTo` 不可 |
| Hide Game Select Back Button | （非推奨・既定 OFF）おとあそびからホームへ戻る |

開発日常用は **Is Exhibition Mode = OFF** のまま。

## 2. ビルド

- メニュー: `Geidai → Build`（`GeidaiBuildScript`）
- または `aidlc-docs/construction/build-and-test/build-instructions.md` の iOS 手順
- Build Settings に Geidai シーンが登録されていること（`Geidai/Scenes/Update Build Settings`）

## 3. 展示当日スモーク（5分）

展示モード ON のビルドで実施。

- [ ] 起動 → Boot を経由せず Home（2ボタン）または Register なしで Home
- [ ] ホームに **おとあつめ・おとつくり** が出ない
- [ ] **おとあそび** → ①②③ のいずれかが起動
- [ ] **ホームにもどる** でホーム（2ボタン）に戻れる
- [ ] **おとずかん** が開く
- [ ] （任意）Rec/音作りへ行けない

## 4. 展示後

`ExhibitionSettings.asset` の **Is Exhibition Mode** を OFF に戻してから通常開発ビルドする。
