## 3. 設計方針

### 3.1 楽器の影（共通 1 枚）

**データ**

- 影はカタログ項目に持たない。**1 つの共有 Sprite**（例: `Assets/Art/Game/InstrumentShadow.png`）をプロジェクトに置く。
- **決定（2026-10-21）**: 須藤さん入稿前は **仮スプライト**で実装し、後から Sprite 差し替えのみで本番化。

**UI 構造（推奨）**

```
InstrumentDisplay (RectTransform)
├── ShadowImage   (Image, 下寄せ・同一スプライト・楽器より手前に描画しない＝先に描画)
└── InstrumentImage (Image, 既存)
```

**コード**

- 新規: `Geidai.Common.UI.InstrumentFloorShadow`（または `InstrumentDisplayRoot`）
  - `[SerializeField] Image shadowImage`
  - `[SerializeField] Image instrumentImage`（任意）
  - `public void ApplySharedShadow(Sprite shadow)` または `ScriptableObject` `InstrumentDisplayTheme` で影参照を 1 箇所管理
- **Game1**: 各 `Choice_*` の Hierarchy を上記に揃える（シーン編集。Build All は使わない）。
- **Game3**: 雲上の楽器／`PitchItem` プレハブに同じ Shadow 子を追加（ドラッグ対象の RectTransform は従来どおり親 or InstrumentImage 側で維持）。

**須藤さんがシーンで触れる範囲**

- 影の **位置・スケール・色**は `ShadowImage` の RectTransform / Image で調整（Sさん向けガイドに 1 段落追記予定）。

### 3.2 図鑑 Editor：削除

**ドメイン**

- `CuratedSoundCatalog.RemoveById(string id)` を追加（リストから除去、Undo 対応は Editor 側で `RecordObject`）。

**ガード（保存前検証）**

| チェック | 失敗時メッセージ例 |
|----------|-------------------|
| id 空 / 存在しない | 削除対象なし |
| `UnlockRulesCatalog` に `soundId` 参照 | 「アンロック条件で使用中のため削除できません」 |
| （任意）`Game3Config` 等の手動参照 | 初回は **警告のみ** またはスコープ外とし、ドキュメントで「Inspector から clip を外す」 |

**WAV / AudioClip**

- **決定（2026-10-21）**: カタログ行のみ削除。**`Assets/Audio/Library` のファイルは削除しない**（ファイル削除 UI も付けない）。

**UnlockState**

- 端末保存の `unlockedIds` に残った ID は **無害**（一覧に無い ID は表示されない）。初回は **掃除しない**。必要なら後続で「孤立 ID 整理」ツール。

**UI**

- フォーム下部に **「削除」**（赤系は `GUI.skin` 任せ）。`EditorUtility.DisplayDialog` で確認（表示名・id 表示）。

### 3.3 図鑑 Editor：並べ替え

**意味**

- プレイヤー図鑑は **図鑑ナンバー昇順**固定。並べ替えは **`encyclopediaNumber` の入れ替え／再採番**で表現する。

**UI（IMGUI・左ペイン）**

- 選択中の行に **「↑」「↓」**（先頭/末尾は片方 disabled）
- 操作: ソート済みリスト上の **隣接要素と `encyclopediaNumber` をスワップ**（Undo 1 回）
- **決定（2026-10-21）**: **↑↓ の番号スワップのみ**。連番振り直しボタンは作らない。

**番号の隙間**

- 既存データに 1,3,5 のような隙間があっても **スワップのみ**なら番号体系は維持。

**実装**

- `CuratedSoundCatalogEditorOps.SwapEncyclopediaNumbers(catalog, idA, idB)` または `MoveInSortedOrder(catalog, id, delta)`
- 保存は即 `SetDirty` + `SaveAssets`（タグ CRUD と同様）

## 6. 決定事項（2026-10-21）

| # | 質問 | 決定 |
|---|------|------|
| 1 | 影スプライト | **仮素材で実装** → 後から差し替え |
| 2 | 削除時の音声ファイル | **消さない**（カタログ行のみ削除） |
| 3 | 並べ替え UI | **↑↓ のみ**（連番振り直しは不要） |
| 4 | ゲームの楽器絵と図鑑 `image` の一致 | **今回のスコープ外**（下記） |

### 補足：質問 4 の意味（今回やらない理由）

- **おとずかん**では、カタログに登録した **楽器のイラスト（`image`）** を一覧・詳細に表示している。
- **音合わせ・音並べ**では、今はシーン上に置いた絵や別設定（例: Game3 の `Game3Config` の AudioClip リスト）で動いており、**図鑑と同じ絵が自動では出ない**。
- 「4」は「ゲーム中のベルの絵も、図鑑で登録した絵と常に同じにするか？」という話。**影の追加とは別の大きめの作業**（出題音とスプライトの紐付け）なので、**今回の PR には含めない**。必要になったら別計画（カタログ ID で Game1/3 に Sprite を引く）にする。
