# 音図鑑 編集手順書（コンテンツ担当向け）

制作側の音（ベル・ドラムなど）を、**コードを書かずに** Unity Editor から登録・編集するための手順です。  
対象: 企画・デザイン担当（Sさんほか）。アプリを遊ぶ子ども向けのひらがな表記は使いません。

困ったら前本へ。C# やシーン再生成が必要な作業は前本側です。

関連: [Sさん向けガイド.md](Sさん向けガイド.md)（見た目・お題など全般）

---

## 1. できること／できないこと

### できること（この手順書の範囲）

- WAV などの音声を取り込み、音図鑑カタログに追加・更新する
- 表示名・図鑑ナンバー・説明・画像・カテゴリ・音色タグなどの属性を編集する
- 音色タグ語彙の追加・変更・削除（参照中は削除不可）
- Editor 上で試聴する
- Play モードでプレイヤー向け図鑑の見え方を確認する

### 前本に任せること

- アンロック条件の変更、ゲーム出題ロジック
- シーンの見た目レイアウトの大幅変更
- `Geidai/Scenes/Build All Geidai Scenes` の実行（見た目が消える）
- ビルドエラー・実機不具合の調査

---

## 2. 準備

1. Unity Hub でこのプロジェクトを開く（**Unity 6000.4.2f1**）
2. メニュー **Geidai → Library → Curated Sound Catalog** で登録ウィンドウを開く
3. 上部が次の既定アセットになっていることを確認する

| 欄 | 既定アセット |
|---|---|
| カタログ | `Assets/Settings/CuratedSoundCatalog_Default.asset` |
| 音色語彙 | `Assets/Settings/TimbreTagCatalog_Default.asset` |

ウィンドウ構成:

| 位置 | 内容 |
|---|---|
| 左 | 登録済みの音一覧／「追加」 |
| 中央 | 選択中の音の属性フォーム・試聴・WAV 取り込み・保存 |
| 右 | 音色タグの一覧と CRUD |
| 上 | 常時表示のヘルプ／結果メッセージ |

---

## 3. 新しい音を登録する

1. 左の **「追加」** を押す（中央が新規フォームになる）
2. **必須項目**を入れる（下表の *）
3. **WAV インポート**
   - 「選択」で PC 上の音声ファイルを選ぶ（wav / mp3 / ogg / aiff）
   - **先に `id` を入れてから**「取り込み」を押す  
     → `Assets/Audio/Library/{id}.拡張子` にコピーされ、AudioClip が付く
4. 画像があれば「画像」欄に Sprite を指定（後述）
5. **「試聴」** で音を確認（「停止」で止める）
6. **「保存」** を押す  
   → 左の一覧に載る。失敗時は上部メッセージに理由が出る（保存されない）

### 必須・任意フィールド

| 項目 | 必須 | 説明 |
|---|---|---|
| id | * | 安定した英数字 ID（例: `demo_bell`）。Unlock・他機能の参照に使うので、後から安易に変えない |
| 図鑑ナンバー | * | 1 以上の整数。一覧の並び順。カタログ内で重複不可 |
| 表示名 | * | プレイヤーに見える名前 |
| カテゴリ | * | 絞り込み用（例: `金属`、`テスト`）。自由記述。同じ文字列がドロップダウンに集約される |
| 音色タグ | * | 右ペインの語彙から選択（例: ベル / ドラム） |
| AudioClip | * | 取り込み、または既存 Clip を指定 |
| 読み | 任意 | ふりがな |
| 説明 | 任意 | 詳細パネルに表示 |
| 画像 | 任意 | 無い場合はアプリ側のプレースホルダー |
| 基準ピッチ MIDI | 任意 | `-1` = 未設定。ピッチ系ゲーム用（0〜127） |
| 強弱帯／長さ帯 | 任意 | Soft/Mid/Loud、Short/Mid/Long など |
| pairKey | 任意 | 神経衰弱など向け |
| allowPitchShift | 推奨 true | 実行時ピッチシフト可否 |
| difficultyTags | 任意 | カンマ区切り |
| 初期解除 | 任意 | オンだと最初から聞ける |

---

## 4. 既存の音を編集する

1. 左一覧で対象をクリック
2. 中央で項目を修正
3. 音声を差し替える場合は、同じ `id` のまま WAV を取り込み直すか、AudioClip を差し替える
4. **「保存」**

`id` を変えると別物扱い／参照切れの原因になるので、原則変えません。表示名や説明だけ変えるのが安全です。

---

## 5. 試聴のしかた

- 中央の **「試聴」** … Editor 内で再生。**「停止」** で止める  
- または Project で AudioClip を選び、Inspector の再生ボタン

上部メッセージ枠は常にあり、通常は操作のヒント、試聴・保存後はその結果に切り替わります。

---

## 6. 画像の入れ方

1. PNG などを `Assets/Art/Library/Icons/` に置く（推奨）
2. ファイルを選び、Inspector で **Texture Type = Sprite (2D and UI)** → Apply
3. 登録ウィンドウ中央の「画像」にドラッグ、または ○ から選択
4. 「保存」

サンプル: `demo_bell.png` / `demo_drum.png`（仮アイコン。本番用に差し替え可）  
未設定時の枠用: `placeholder.png`

## 7. 音色タグの管理（右ペイン）

### 追加
1. **「タグ新規フォーム」**
2. `tag id`（英数字、例: `metal`）、表示名（例: `金属`）、sort（小さいほど上）
3. **「タグを保存」**
4. 中央の「音色タグ *」ドロップダウンにも出る

### 編集
1. 右の一覧でタグ名をクリック（下が編集フォームになる）
2. 表示名などを変えて **「タグを保存」**

### 削除
- 右の **×**
- **音が参照しているタグは削除できません**（例: サンプルの `bell` / `drum`）
- 未使用タグだけ消える

先にタグを用意してから、音の「音色タグ *」で割り当てる流れがおすすめです。

---

## 8. プレイヤー画面での確認

1. Editor で **Play**
2. ホーム → **おとずかん**
3. 確認ポイント:
   - 図鑑ナンバーの昇順
   - カテゴリ／音色の絞り込み
   - 行を選ぶと下（または横）に説明など
   - 画像・ロック表示・解除済みの「きく」

※ ユーザーが録音した音（コレクション）はこの画面には出ません。

## 9. フォルダとアセットの場所

| 用途 | パス |
|---|---|
| 音カタログ | `Assets/Settings/CuratedSoundCatalog_Default.asset` |

## 10. よくあるトラブル

| 症状 | 対処 |
|---|---|
| 保存できない | 必須欠落、id／図鑑ナンバー重複、音色タグ未選択を上部メッセージで確認 |
| 取り込みできない | 先に `id` を入れる。パスが正しいか確認 |
| タグが消えない | どれかの音がそのタグを参照していないか確認 |
| Play しても一覧に出ない | 「保存」したか。必須が揃っているか（不完全な定義は一覧から除外される） |
| シーンの見た目が消えた | `Build All Geidai Scenes` を押していないか。押した場合は前本へ |

---

## 11. おすすめの作業の流れ

1. 音色タグを先にそろえる（右ペイン）
2. 画像を `Icons/` に Sprite として用意する
3. 「追加」→ id・ナンバー・名前・カテゴリ・タグ → WAV 取り込み → 画像 → 試聴 → 保存
4. Play でおとずかんを確認
5. 問題なければ Git にコミット、または変更を前本に共有
