## 3. プロジェクト概要

| 項目 | 内容 |
|------|------|
| 正式名称 | 「音」から始まる、耳のためのアプリケーションの考案 |
| 枠組み | 東京藝大アートDX **学内公募研究（2026年度）** 採択 |
| 企画主体 | 学内公募研究プロジェクト |
| 着想 | スイス音楽教育家 **エドガー・ウィレムス** のメソッド（第1〜2段階に注目） |
| 位置づけ | 音楽教育の前段としての**音響教育**（「演奏」より「聴く」に重き） |

### 公募概要（Art DXページより）

音楽教育では演奏技術の習得や理論の学習に重点が置かれる一方で、「聴く力」を育てる機会は十分とはいえない。本考案では、ウィレムスの教育メソッドの導入段階（身の回りの音に耳を傾ける）から、音の高さや長さを図やグラフで表しながら理論の学習へとつなげる流れを、スマートフォン・タブレット向けアプリとして実現することを目指す。

## 4. アプリのコンセプトと目的

### コア体験

**録音 → 加工 → 自身の音で「聴き分ける」オムニバス型ミニゲーム**

### 開発目的

1. 「きく」ことを目的とした時間や取り組みの促進し、広く実践するため（耳の育成は音楽学習の基礎であり、生涯学習にも貢献しうる）
2. 誰もが継続的に行える可能性の探究

### 対象ユーザー

| 資料 | 対象 |
|------|------|
| 作品コンセプト.pdf（新） | 音楽学習者全般、「聴く」ことに興味がある人 |
| 0427構想.pdf（旧） | 3歳から12歳までの子ども、音楽学習者全般、「聴く」ことに興味のある人、音楽教育者（授業・レッスンでの導入） |

※ 対象年齢の記載は資料間で差異あり。最新版（作品コンセプト.pdf）では年齢限定の記載なし。

### プラットフォーム

**スマートフォン・タブレット**（場所や経済状況に左右されず、誰もが継続的に「聴く力」を育める環境）

### ねらい

- 「音の世界」に対するユーザーの**主体的な参加**
- 「音教材」の不足の解消
- 教育を実施・享受できる機会の拡張
- ユーザーの**継続性・再現性**
- データの収集のしやすさ

### 期待される効果

1. 身近なデバイスを用いて「新しい耳の教育」を広く広められる
2. 「体験」だけでとどまらず、継続性を図れる
3. 現行音楽教育に欠けがちな「聴覚的感受性」へのアプローチを、誰もに広く届けられる（対面実施は再現性が低いのが現状）
4. データの採取（使用前後の比較、意見など）がしやすい

### 差別化ポイント

既存アプリ調査（背景資料より）:

| カテゴリ | 代表例 | 本アプリとの違い |
|----------|--------|------------------|
| 音楽配信 | Apple Music, Spotify | 聴き方はユーザーに委ねられる |
| 音で遊ぶゲーム | 各種 | 音がなくとも成り立つゲームが多い（視覚的アプリ） |
| 幼児向け知育 | 各種 | 音以外の学習（動物・英語等）が主目的のものが多い |
| 音楽制作 | GarageBand 等 | 「制作」が目的 |
| 音の記録 | フィールドレコーディング系 | 記録・共有が主目的で、主体的に聴いているかは不明 |
| 音楽活動補助 | メトロノーム、チューナー | 演奏支援が主目的 |
| 西洋式音楽教育 | 各種 | 楽音・楽譜・平均律ピッチ基準。中級者以上向けが多い |

**本アプリの位置づけ**: 「音を主体的に、耳を澄まして聴くこと」を目的とした、「音を聴く」「音を発する」ことで初めて成り立つアプリ（視覚情報なしでも成り立つ、「音の、音による、耳のため」のゲームアプリ）。

### 着想の背景（ワークショップ経験より）

- **公園での経験**: 耳を澄ますほど聞こえる音が増えた経験から、「音」を聞く習慣がなかったことを痛感
- **無声映画ワークショップ**（小学3-4年生25人）: 子どもたちを音の世界に招き入れたが、「体験」で止まり継続性が見込めない、機材依存で再現性が低い、子どもたちの意識が「音を聴く」より「音を鳴らす」「加工」に向いた
- **個人レッスン**（GarageBand使用）: 音の技術から可能性を発見できたが、機械を触ることへの興味の方が大きかった
- **現段階の認識**: 録音・加工は音への興味喚起に寄与するが、「音を聴く」ことはそれと切り離した地点で行う必要がある。誰もが手軽に扱えるもの（再現性）としてアプリ実施が最適ではないか

### ③ 共有機能に代わる音図鑑／音づくり案

ユーザー間共有は、不適切利用への対応、審査、サーバー運用、継続費用が必要になるため、第一弾では見送る。代わりに、次の完全オフライン機能を次期MVPへ含める。

- 制作側で確認済みの音素材を50〜100音程度アプリへ同梱する
- ゲームクリアと指定音の録音・保存課題を組み合わせ、利用できる音素材を端末内でアンロックする
- アンロック済み素材を2音選び、音量・ピッチ・リバーブ・音色等を調整して「音を作る」
- 元音声を複製せず「素材ID＋加工パラメータ」のレシピを保存し、再編集可能にする
- 必要な場合は、レシピから完成音をWAVEへ書き出せるようにする
- 素材カタログとレシピは安定したIDで参照し、素材更新後も可能な範囲で再生互換性を保つ

**段階導入案**:

1. 音素材カタログの閲覧・試聴
2. ゲーム進行によるアンロックと端末内保存
3. 2音の組み合わせ・加工・試聴
4. レシピ保存・再編集
5. 任意のWAVE書き出し
6. ゲームから音図鑑／音づくりへ循環する導線

**容量方針**: 初期カタログは50〜100音程度を目安とし、音声圧縮後の実ビルド容量と実機メモリを測定して段階的に増やす。ユーザー録音や書き出し音は別枠で容量上限を検討する。

### ① Rec 画面の仕様

| 領域 | 内容 |
|------|------|
| **上部** | 録音/停止ボタン、再生ボタン。録音時間は **3秒固定** |
| **中部** | 4種のスライダー（再生時に反映。保存時も加工済みで保存） |
| **下部** | 保存ボタン、ホームに戻るボタン |

**加工スライダー**:

| # | 項目 | 仕様 |
|---|------|------|
| 1 | リバーブ | -10000 〜 0 |
| 2 | ノイズリダクション | 0 / 弱 / 中 / 強（4段階） |
| 3 | ピッチ調整 | -1200 〜 1200（要検討。微分音に絞る可能性あり） |
| 4 | 音色エフェクト | なし / ロボット / コーラス / あと1種類 |

各スライダー上にバイパス（on/off）を置く案あり。操作性が悪ければ省略。

| ★★★ 中 | **⑦音迷路** | 同左 | ○ | — | 中 |
| ★★ 低〜中 | **⑧音探し** | 同左 | — | ○ | **高**（3D・時間がかかる） |

### 6.2 共通パラメータ

多くのゲームで以下のパラメータを設定可能:

| パラメータ | 意味 |
|-----------|------|
| 出題数 | ラウンド数 |
| 遊ぶ音の数 | おたまじゃくし（選択肢）の数 |
| 難易度 | かんたん / ふつう / むずかしい / とても難しい（ピッチ系ゲームのみ） |

**難易度とピッチ間隔（セント）** — 隣接音のピッチ差:

| 難易度 | セント差の候補 |
|--------|---------------|
| かんたん | 300 / 400 / 500 |
| ふつう | 100 / 150 / 200 |
| むずかしい | 20 / 25 / 50 |
| とても難しい | 0.5 / 1 / 2 / 5 / 10 |

### 6.3 各ゲーム概要

#### ①音合わせ ★★★★★

- **目的**: 音色・音高・強弱の聞き分け（音の長さは検討中）
- **UI**: 蓮の上のカエル（お手本）＋複数のおたまじゃくし。タップで音確認、ドラッグで答え合わせ
- **成功**: おたまじゃくしがカエルに進化
- **研究会で検討**: 出題数・おたまじゃくし数の上下限、各難易度の音域・微分音の扱い

#### ②音並べ ★★★★★

- **目的**: 音高・強弱の並べ替え（強弱は視覚デザインが課題）
- **UI**: 五線＋蓮/泡の上におたまじゃくしを配置。低い順/高い順/ランダム（ジグザグ）
- **成功**: 全おたまじゃくしがカエルに進化。完成ボタンで左から順に再生

#### ③音の神経衰弱 ★★★★

- **目的**: 音の記憶・ペア合わせ
- **ルール**: トランプ形式。6/8/10/12/18枚から選択。音色・音高（強弱は環境依存で検討中）
- **研究会で検討**: 難易度＝枚数か聞き分けか、18枚は多すぎか、ペア成立時の回収方法

#### ④カエルコーラス ★★★★（旧: 音の錬金術）

- **目的**: 和音・重なった音色の聞き取り
- **ルール**: カエルが2〜4音を同時再生 → 同じ組み合わせのおたまじゃくしを集めて「決定」
- **デザイン**: 音合わせのUIを転用予定

#### ⑤かえるわたし ★★★★（旧: リズムメイキング）

- **目的**: 音の長さを線の長さで表現
- **ルール**: メロディ再生（拍の視覚補助あり）→ 指で線を引く → カエルが線に沿って歩行・ジャンプ
- **拍**: 4拍×2段 または 3拍×2段。難易度は音価の複雑さで調整

#### ⑥コインバード ★★★

- マイク入力・リアルタイム音高検出が必要なため、**実装難易度を考慮して優先度を下げている**。

#### ⑦音迷路 ★★★ / ⑧音探し ★★

- 詳細仕様は「後日更新」予定（7/10版）。音探しは3Dのため優先度低

### 6.4 削除・改称

| 旧名称 | 扱い |
|--------|------|
| リズムタップ | 削除 |
| 音の種類分け / 音片付け | 削除 |
| サウンドクッキング | **カエルコーラス** に改称・再設計 |
| リズムメイキング | **かえるわたし** に改称 |
| 音重ね | 7/10版には未記載（カエルコーラスに統合？要確認） |

### 6.5 技術検討事項

> 保存済みの音を素材に、ゲーム出題用に**リアルタイムでピッチ加工**（例: オリジナル、+10セント、+20セント、-10セントを生成）して遊ばせることは可能か？遊び終わった加工音は保存しない想定。

### 6.6 ゲームから期待されること

1. 音を「主体的に聴く」ことの継続化
2. 「耳の感覚性」および「耳の知性」の発達
3. 場所によらない教育機会の提供
