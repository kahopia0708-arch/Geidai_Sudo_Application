## ① 音合わせ

| 項目 | 依頼内容 |
|------|----------|
| モチーフ | おたまじゃくし → **サウンドライブラリのイラストと音** |
| お手本側 | **魔法使い（師匠）** |
| 選択肢 | 図鑑イラストを **魔法使いの弟子** が持つイメージ |
| 操作 | 弟子の近くで選択肢を離すと **吸着**し、**弟子の手元**にイラストが移動 |
| 影 | 画面デフォルトで **影イラスト** を表示。楽器を **移動中**、または **師匠・弟子がイラストを持っているとき** は影を **非表示** |
