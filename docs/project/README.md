# 企画・保存資料（リポジトリ正本）

藝大 須藤さんアプリの**企画・構想・打ち合わせ・仕様**の保存場所です。  
開発・AI 作業では **ここを正（Source of Truth）** として読み、変更も Git で履歴を残します。

## 構成

| パス | 内容 |
|------|------|
| [プロジェクト概要.md](./プロジェクト概要.md) | 全体サマリ・優先順位・未確定事項（**作業の起点**） |
| [修正点まとめ_20261029.md](./修正点まとめ_20261029.md) | UI・素材・影など最新の修正依頼（10/29） |
| [input/](./input/) | 一次 PDF / 画像（打ち合わせ・仕様・コンセプト等） |

## 資料の優先順位（概要）

1. **画面・素材・影** → `修正点まとめ_20261029`（8/18 と矛盾する場合は 10/29 優先）
2. **展示範囲・ゲーム一覧・担当** → `input/打ち合わせ記録_20260818.pdf`
3. **Rec・コレクション等** → `input/ゲームの仕様について_20260710.pdf` ほか

詳細は `プロジェクト概要.md` 内の表を参照。

## Google Drive との関係

以前は Drive のみに置いていました。**今後はリポジトリを正**とし、Drive は共有・バックアップ用のミラーとして運用できます。

- **Drive ミラー（任意）**:  
  `~/Library/CloudStorage/GoogleDrive-.../マイドライブ/docs/202607.藝大_須藤さん`
- **Drive → リポジトリへ取り込み**:  
  `./scripts/sync-project-docs-from-drive.sh`（ローカルに Drive がある場合）

## 大容量 PDF（0427 版など）

`input/` には実装判断に直結する資料を優先して同梱しています。  
4月版の大型 PDF（構想・背景・アイディア集、合計約 150MB）は Git サイズの都合で**同梱していません**。必要なら上記 sync スクリプトで `--full` を付けて取り込むか、Drive から直接参照してください。

## 更新手順

1. 内容を更新したら `docs/project/` 内の該当ファイルを編集（または Drive から sync）
2. `プロジェクト概要.md` の「最終更新」行を更新
3. コミットメッセージに日付・資料名を書く
