# U1 基盤 — Business Rules（業務ルール・検証・制約・エラー方針）

**ユニット**: U1 基盤
**作成**: 2026-07-15 / AI-DLC CONSTRUCTION / Functional Design（Part 2）

---

## 1. 入力検証（UserProfile / Q1=B, SECURITY-05）
- **BR-01**: `birthYear` は 1900〜当年の範囲。UI は年の**選択式（ドロップダウン）**とし、未来年を選べない。範囲外は保存拒否。
- **BR-02**: `nickname` は前後空白除去後 **1〜8 文字**、空不可。超過/空は保存拒否し、その場で通知（アイコン＋平易文言）。
- **BR-03**: 検証失敗時は `ValidationError`（項目・理由）を返し、保存/確定を行わない。

## 2. 永続化ルール（Q2=A / NFR-07 は U4 で強化）
- **BR-04**: `id` は GUID を採番。ファイルは `sounds/{id}.wav` と `sounds/{id}.meta.json` の対。`profile.json` は単一。
- **BR-05**: 読込時、`wav` と `meta.json` の**対が揃っている項目のみ**有効。片方欠損/破損は該当項目を読み飛ばす（クラッシュしない）。
- **BR-06（U1最小）**: 保存は「書き込み→確認」の基本手順。**原子的置換（temp→rename）・詳細な堅牢性は U4 で本実装**。
- **BR-07**: PII（生年/ニックネーム/写真/メモ）は端末外へ送信しない。ログにも出力しない（NFR-04）。

## 3. 音声/WAV ルール（Q4=A）
- **BR-08**: 保存フォーマットは WAVE 16bit PCM・44100Hz・モノラル・3秒固定（132,300 サンプル）。
- **BR-09**: ステレオ入力はモノラルへダウンミックスしてから保存。
- **BR-10（不変条件 / PBT）**: `WavCodec.Decode(WavCodec.Encode(buffer)) ≈ buffer`（サンプル数・値の一致、許容誤差内）。
- **BR-11（不変条件 / PBT）**: `PitchMath.RatioToCents(CentsToRatio(c)) ≈ c`、`pitchSemitones` は -12〜+12 にクランプ。

## 4. ナビゲーション（Q5=A / FR-02, US-TECH-04）
- **BR-12**: 遷移は `SceneId`（列挙）で型安全に行う。文字列直指定は禁止（大文字小文字不一致の不具合を排除）。
- **BR-13**: `Place` は `SceneId` に含めず、導線からも除外（MVP 無効化）。
- **BR-14**: 初期遷移 — 初回（`profile.json` なし）: Main→登録フロー→Home。登録済み: Main→Home。登録は Home 内フローで提示。
- **BR-15**: 存在しない/未対応の遷移要求は安全に無視し警告（クラッシュしない）。

## 5. エラー/フォールバック方針（Q6=A＋補足, SECURITY-15）
- **BR-16**: 失敗はユーザーへ**アイコン＋短い平易な文言**（必要に応じ音）で通知。子どもが理解できる表現。
- **BR-17**: 内部ログに詳細を残す場合も **PII は出力しない**。
- **BR-18（補足反映）**: 自動フォールバックは**本当に非致命かつ回復可能な場合のみ**行う。**誤動作を正常と誤認させるような過度なフォールバックは禁止**。
- **BR-19（補足反映）**: フォールバックが発動したときは**警告を出す**（ユーザーへの適切な通知＋内部の warning ログ。PII なし）。例: 破損項目の読み飛ばし時に「一部の音を読み込めませんでした」を提示。
- **BR-20**: マイク権限拒否時は録音を行わず、権限が必要な旨を平易に案内（U3 で利用）。

## 6. UI 基盤ルール（NFR-11/12。数値は NFR Design）
- **BR-21**: すべての画面ルートに SafeArea 追従と レスポンシブ Canvas 設定を適用（縦横両対応）。
- **BR-22**: 見た目の詳細（余白/配色/素材/文言）は Sさん が Prefab/UITheme/ScriptableObject で調整可能にする（US-TECH-07）。前本はコード改修不要な調整余地を残す。
