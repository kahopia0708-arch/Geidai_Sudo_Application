# U1 基盤 — NFR Requirements（非機能要件・受入値）

**ユニット**: U1 基盤
**作成**: 2026-07-15 / AI-DLC CONSTRUCTION / NFR Requirements（Part 2）
**決定**: Q1〜Q7＝すべて A（推奨）
**入力**: `../functional-design/*`、`../../../inception/requirements/requirements.md`（NFR-01〜12）

> U1（UI基盤＋Services器＋Common）に適用する非機能目標と受入可能値。完全オフライン・ローカルのみ（NFR-02）のため、可用性/スケーラビリティ/DR は端末内・アプリ内範囲。

---

## 1. プラットフォーム（NFR-01 / Q1=A）
- **対象OS**: iOS 15+ / Android 8.0（API 26）+ を目標レンジ。MVP はどちらか片方から着手。
- **端末**: スマホ〜タブレット。**画面向きは縦・横 両対応**。
- **受入**: 目標レンジ内の入手可能な実機で主要フロー（起動→登録→ホーム→空画面遷移）が動作。

## 2. レスポンシブ UI（NFR-11 / Q2=A）
- **CanvasScaler**: Scale With Screen Size、**参照解像度 1080×1920**、**Match=0.5**（縦横中間）。全 Canvas 共通。
- **広アスペクト（タブレット等）**: Anchor＋レイアウトグループで吸収。固定ピクセル依存を排除。
- **受入**: 主要アスペクト比（19.5:9〜4:3）・縦横で、空画面テンプレートのヘッダ/コンテンツ/フッタが破綻せず操作要素が収まる。

## 3. Safe Area（NFR-12 / Q3=A）
- **方式**: 各画面ルートに `SafeAreaFitter`。`Screen.safeArea` からアンカーを**表示時＋解像度/向き変更時に再計算**。`androidRenderOutsideSafeArea=1` と整合。
- **受入**: ノッチ/パンチホール/ホームインジケータ端末で、縦横いずれも操作要素が safeArea 内に収まる。

## 4. パフォーマンス（NFR-06 / Q4=A）
- **画面遷移**: 体感即時（目安 < 0.3s）。
- **起動**: 数秒以内。
- **保存（WAV 書込, U1 最小経路）**: 体感即時（目安 < 0.5s）。
- **フレームレート**: ターゲット 60fps、最低 30fps を割らない。
- **受入**: 上記目安を主要端末で満たす（詳細計測は Build & Test）。

## 5. データ堅牢性（NFR-07 / Q5=A）
- **U1（最小）**: 基本保存＋対ファイル整合チェック（BR-05）。破損/欠損は読み飛ばし。
- **U4（本実装）**: 原子的置換（temp→rename）・詳細フォールバック。
- **共通**: フォールバック発動時は**必ず警告**（BR-19）。過度なフォールバック禁止（BR-18）。
- **受入**: 破損メタ/欠損 WAV を混在させても U1 の読込がクラッシュせず、警告が出る。

## 6. セキュリティ/プライバシー（NFR-04 / Security）
- PII（生年/ニックネーム/写真/メモ）は端末外送信禁止・ログ非出力。
- 入力検証（BR-01〜03 / SECURITY-05）。本番ビルドで詳細エラー非表示（SECURITY-09）。
- **受入**: ネットワーク送信が無いこと、ログに PII が出ないことを確認。

## 7. テスト容易性（NFR-09 / PBT / Q6=A）
- **PBT 対象**: `WavCodec` ラウンドトリップ、`PitchMath` 逆変換、設定/メタ JSON シリアライズのラウンドトリップ。
- **フレームワーク**: FsCheck ＋ Unity Test Framework（EditMode）。
- **受入**: 上記 3 種の property テストがグリーン。

## 8. 保守性（NFR-08 / NFR-10 / Q7=A）
- Assembly Definition でモジュール分割（`Geidai.Common`/`Geidai.Services`/…）。
- 永続化は Unity 標準 `JsonUtility`（不足時のみ軽量 JSON を検討）。
- Git ブランチ＋PR レビュー＋変更メモ（NFR-10）。Unity MCP 経由のシーン操作（US-TECH-05）。
- **受入**: モジュール境界でビルドが通り、循環依存が無い。

## 9. ユーザビリティ（NFR-05）
- 子ども/初心者が扱える簡潔UI。失敗はアイコン＋平易文言（BR-16）。
- 見た目詳細は Sさん が UITheme/Prefab で調整（US-TECH-07）。
- **受入**: 空画面テンプレート＋UITheme 差し替えで見た目が変わることを確認。

## 10. 可用性/スケーラビリティ/DR
- **N/A（ローカル・オフライン）**: サーバー無し。端末内で完結（NFR-02）。RESILIENCY のクラウド系ルールは N/A。
