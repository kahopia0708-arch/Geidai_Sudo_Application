# Build Instructions — Fさん導入ドキュメント

本ワークストリームは Markdown のみ。Unity ビルドは不要。アプリ本体の手順は既存 `build-instructions.md` を正とする。

## Prerequisites

- Git 作業コピー（ブランチ `feature/onboarding-f-guide`）
- 成果物ファイルがワークスペースにあること

## Build Steps

1. 次が存在することを確認する
   - `docs/Fさん向けガイド.md`
   - `docs/Sさん向けガイド.md`
   - `README.md`
2. Unity プロジェクトのコンパイルや APK 生成は行わない

## Verify Build Success

- 上記 3 ファイルが読める
- C# / `.unity` シーンに本ワークストリーム由来の差分がない
