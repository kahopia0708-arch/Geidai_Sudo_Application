## 1. 画面構成（Rec 画面・単一画面 / Q7=A）

`Rec` シーンを 1 画面として構成する（録音〜加工〜保存を同一画面で完結）。

```
[Rec 画面]
├─ ヘッダ: タイトル「ろくおん」 / もどる(ホーム)ボタン
├─ 録音セクション
│   ├─ 録音ボタン（大・中央）
│   └─ 残り時間表示（3→0 カウントダウン / 録音中インジケータ）
├─ 再生セクション
│   ├─ 再生ボタン / 停止ボタン（Recorded 以降で活性）
│   └─ 録り直しボタン
├─ 加工パネル（EffectPanel）
│   ├─ ピッチ（半音スライダー ±12）           ＋ バイパス
│   ├─ ノイズ低減（None/弱/中/強 の 4 択）      ＋ バイパス
│   ├─ 音色（なし/ロボット/コーラス系 の 3 択）  ＋ バイパス
│   ├─ リバーブ（0〜1 スライダー）             ＋ バイパス
│   └─ 全体 on/off（一括バイパス）
├─ 保存ボタン
└─ エラー/通知バナー（ErrorPresenter 再利用）

[保存プロンプト（SavePrompt・オーバーレイ）]
├─ タイトル入力（任意 / 未入力は既定名）
├─ 保存する / キャンセル
└─ （保存中インジケータ → 「保存できたよ」通知）

[破棄確認（ConfirmDialog 再利用・離脱時のみ）]
└─ 「ほぞんしないで もどる？」 はい / いいえ（既定=いいえ）
```

## 2. コンポーネント（ふるまいの責務）

| コンポーネント | 種別 | 責務 |
|---|---|---|
| `RecScreenController` | ScreenRootBase 継承 | 画面ライフサイクル、`RecordingState` の統括、各サブコントローラの調停、`OnBackPressed`（離脱・破棄確認）。 |
| `RecordingController` | 部品 | `IAudioService` 経由の録音開始/自動停止/`AudioBuffer` 受領、残り時間表示、権限フェイルセーフ表示連携。 |
| `EffectPanelController` | 部品 | 加工 UI（ピッチ/ノイズ/音色/リバーブ＋各バイパス）を `SoundEffectSettingsData` にバインドし、変更を再生系へ即時反映（非破壊）。 |
| `PlaybackController`（概念） | 部品 | 再生/停止、現在設定での加工再適用（`RecordingController` に内包でも可・NFR/コード生成で確定）。 |
| `SavePromptController` | 部品/オーバーレイ | タイトル入力→確認→`IStorageService.SaveSound` 呼び出し→結果通知。 |
| `ConfirmDialog` | 再利用（U1/U2） | 離脱時の破棄確認（既定フォーカス=いいえ）。 |
| `ErrorPresenter` | 再利用（U1） | 権限不可・保存失敗・遷移失敗の子ども向け通知。 |

## 3. 状態別 UI（活性/表示の要点）

| RecordingState | 録音ボタン | 再生/停止 | 加工パネル | 保存 | 備考 |
|---|---|---|---|---|---|
| Idle | 活性 | 不活性 | 不活性 | 不活性 | 「おして ろくおん」 |
| NoMic | 不活性 | 不活性 | 不活性 | 不活性 | 案内バナー・再試行導線 |
| Recording | 録音中表示 | 不活性 | 不活性 | 不活性 | 残り時間カウントダウン |
| Recorded | 活性(録り直し) | 活性 | 活性 | 活性 | プレビュー可能 |
| Playing | 活性(録り直し) | 停止のみ活性 | 活性 | 活性 | 加工調整は継続可 |
| Saving | 不活性 | 不活性 | 不活性 | 保存中表示 | オーバーレイ待機 |
| Saved | 活性 | 活性 | 活性 | 活性 | 「保存できたよ」通知 |

## 4. 操作フロー（代表）

1. **録音**: 録音ボタン → 権限OK → 3秒録音（カウントダウン）→ 自動停止 → Recorded。
2. **加工プレビュー**: スライダー/選択/バイパス操作 → 再生で聴き比べ（非破壊・即時反映）。
3. **保存**: 保存ボタン → SavePrompt（タイトル任意）→ 保存する → 成功「保存できたよ」/ 失敗は平易通知。
4. **離脱**: もどる/端末バック → 未保存があれば破棄確認 → ホームへ（`NavigationService`）。

---

## 5. レスポンシブ / SafeArea / アクセシビリティ（NFR-05/10/11/12 継承）

- 画面ルートに `ResponsiveCanvasConfigurator`＋`SafeAreaFitter` を適用（縦横両対応）。
- 主要操作（録音・再生・保存）は**大きめのタップ領域**とし、子ども/タブレットで押しやすく（NFR-05）。
- 加工の識別は色＋アイコン＋文字の併用（色覚配慮）。
- 文言はひらがな中心の平易表現（子ども向け）。

---

## 7. 既存 UI（brownfield）との差分

- 既存 `Rec` シーンは `VoiceRecordingSection`＋per-button スクリプト（`GoToRec`/`ReturnHomeButton` 等）構成。
- U3 では `RecScreenController` 系＋`NavigationService` 経由へ統一し、加工 UI を正準モデルにバインド。
- 実シーンの配線・旧コンポーネント差し替え・不要スクリプト削除は **Code Generation 以降で Unity MCP**。
